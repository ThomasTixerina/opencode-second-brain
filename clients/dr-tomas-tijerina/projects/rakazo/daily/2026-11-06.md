## Integraciones (segunda mitad de la sesión)

Se intentó conectar Gmail, Drive, Calendar y los MCP del usuario. **No se logró, y el motivo quedó
documentado a fondo en el `project-context.md`.** Resumen:

- El catálogo de apps de Rakazo requiere `COMPOSIO_API_KEY`. Sin ella las apps se listan pero no
  autentican: exactamente los síntomas que reportó el bot ("falta credencial OAuth", "no disponible
  en este espacio").
- Composio maneja dos tipos de clave: `ck_` (consumer, para clientes MCP) y `ak_` (platform, para el
  SDK). Rakazo necesita `ak_`; el dashboard solo emite `ck_`. Verificado con 401 real.
- El MCP de Composio (`https://connect.composio.dev/mcp`) sí soporta OAuth, pero el formulario de
  alta de Rakazo no ofrece OAuth y la verificación falla antes de poder guardar el servidor.
- Los 23 MCP propios son binarios de Windows (`.cmd`/`.exe`); `gdrive-mcp` además corre con Bun y
  solo cubre Drive.

**Sí se dejó preparado** (útil para la próxima): cuenta verificada, `RAKAZO_ADMIN_EMAILS`,
`MCP_STDIO_ENABLED=true`, `MCP_STDIO_ALLOWED_COMMANDS=npx,node`, `MCP_ALLOW_PRIVATE_ENDPOINT=true`.

Aprendizaje de automatización: la web de Rakazo no expone árbol de accesibilidad y los menús Radix
no abren con `.click()`; hay que disparar `pointerdown`/`mousedown`/`pointerup`/`mouseup`/`click`.


## Decisiones

1. **Stack de imágenes, no `pnpm dev`, como instancia diaria.** `pnpm dev` no tiene política de
   reinicio y murió dos veces; las imágenes traen `unless-stopped` y vuelven solas tras reiniciar.
   Consecuencia aceptada: el código editado no se refleja en la instancia real.
2. **Dos bases de datos separadas** (checkout vs stack) en lugar de compartir Postgres.
3. **Modelo gratuito por defecto**, pago disponible en cuanto se cambie `PI_DEFAULT_MODEL`.
4. **Desactivar ZDR solo para "All other models"**, no para Anthropic/OpenAI/Google, para limitar el
   alcance del cambio de privacidad.
5. **DeepSeek V4.1 Flash como salto de pago**, descartando Qwen3.7-flash pese a ser más barato porque
   no ejecuta tool-calls (inservible para un agente).
