# 2026-06-09 — Voice Widget Bridge IPC

## Resumen
Implementación completa del bridge IPC entre Voice Widget y OpenCode, más corrección PTT infinita y bug de import `log` en todo el package.

## Cambios realizados
- `voice_widget/bridge.py`: **nuevo** — BridgeServer (TCP + subprocess opencode run --format json), BridgeClient, discover_bridge()
- `voice-bridge.py`: **nuevo** — entry point standalone
- `voice_widget/audio.py`: PTT fix (stop_event), bridge-aware type_keys(), set_bridge_client()
- `voice_widget/app.py`: bridge discovery/auto-spawn, _on_bridge_resp callback, _ptt_stop_event, _start_bridge()
- `voice.ps1`: flag --bridge
- **Bugfix:** `from . import log` → `from .log import log` en bridge.py, audio.py, app.py, conversation.py
- **Bugfix:** `_find_opencode()` para resolver shim .ps1 a .exe real

## Decisiones
- Bridge usa `opencode run --format json` (one-shot), no `opencode serve` (simplicidad)
- Bridge reemplaza SendKeys + file watcher cuando está activo
- PTT fix usa `threading.Event()` como señal de cancelación
