## Decisiones
| Decisión | Razón |
|----------|-------|
| 1 skill con 5 fases, no 3 skills | Un solo comando end-to-end; cada fase sigue siendo invocable单独 |
| HTML único + Tailwind CDN | Cero build → el comprador no necesita Node; portable a cualquier host |
| Bilingüe ES/EN por defecto | Duplica el valor de venta; paridad real con `data-es`/`data-en` |
| Stitch opcional con fallback | Nadie se queda sin poder usar el skill por no tener API key |
| Cloudflare Pages como deploy preferido | Gratis, rápido, HTTPS automático, ya usa Cloudflare |
