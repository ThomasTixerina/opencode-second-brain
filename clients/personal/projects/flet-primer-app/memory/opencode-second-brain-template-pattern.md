# opencode-second-brain template pattern

- Recipe for making an Obsidian vault a public template: AGENTS.md + setup scripts + exported workflows + bilingual README + .gitignore with personal patterns
- Always strip credentials from n8n exports before putting in template repos
- Use Path.home() in bridge scripts for cross-machine portability
- hotkeys.json with Mod modifier works cross-platform (Ctrl on Win/Linux, Cmd on Mac)
- .gitignore should exclude plugin binaries but include data.json configs
- Use .gitkeep for empty directories in templates
