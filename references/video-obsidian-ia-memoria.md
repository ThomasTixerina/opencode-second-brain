# Obsidian reventó la IA con MEMORIA GRATIS e ILIMITADA

## Resumen

Video que muestra cómo Obsidian + IA (Codex, Claude, Gemini) funciona como un segundo cerebro. Cubre 5 casos de uso: organización automática, relaciones, canvas, plugins, privacidad.

## Puntos clave

1. Obsidian es **local-first, privado, gratuito** — los archivos son markdown plano
2. El plugin **AI Codex** permite que un agente IA lea/escriba directamente en la vault
3. Se pueden usar **modelos locales** (Ollama, LM Studio) para privacidad total
4. Las **vaults** son simplemente carpetas con archivos .md — cualquier herramienta puede acceder
5. La IA puede **organizar, resumir y relacionar** notas automáticamente

## Aplicación al plan

- El AI Codex plugin es el modelo a seguir para el puente Gemini→Obsidian
- La vault de markdown es el formato universal
- Los modelos locales eliminan dependencia de nube
